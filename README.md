# Inventory Management — Product Entry Form

A responsive browser-based inventory form concept for entering product information. The interface focuses on a clean product-entry workflow and client-side form feedback.

![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?style=flat-square&logo=bootstrap&logoColor=white)

## Form highlights

- Product name and description fields
- Quantity input with minimum-value validation
- Floating-label form controls
- Inline validation feedback
- Success message UI after a valid submission
- Responsive layout for mobile and desktop

## Technology stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ghinaulhasan/Inventory-Form.git
   cd Inventory-Form
   ```
2. Open `index.html` in a browser or run it with VS Code Live Server.

## Important

This repository is a front-end form interface. The current page should not be treated as a complete stock-management database or point-of-sale system unless a backend and persistent storage are added and tested.
